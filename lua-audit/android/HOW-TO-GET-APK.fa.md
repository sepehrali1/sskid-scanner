# گرفتن APK از گیت‌هاب — راهنمای خیلی ساده

هدف: گیت‌هاب برایت APK بسازد و تو دانلودش کنی. لازم نیست برنامه‌نویسی بدانی؛
فقط چند کلیک است. کل کار حدوداً ۱۰ دقیقه وقت می‌برد.

---

## مرحلهٔ ۰ — چیزهایی که لازم داری

- یک حساب گیت‌هاب (رایگان). اگر نداری: <https://github.com/signup>
- فایل `SskidScanner-source.zip` که کنار همین راهنما هست.

**کاری که باید بکنی:** فایل zip را روی کامپیوترت **Extract** کن (راست‌کلیک → Extract All).
بعد از Extract، این‌ها را می‌بینی:

```
lua-audit\        ← پوشهٔ اصلی (این را آپلود می‌کنیم)
.github\          ← ممکن است مخفی باشد؛ به آن کاری نداریم
```

> برای دیدن پوشهٔ `.github` در ویندوز: در File Explorer برو به **View → Show → Hidden items**.

---

## مرحلهٔ ۱ — یک مخزن (Repository) بساز

1. برو به <https://github.com/new>
2. **Repository name**: بنویس `sskid-scanner`
3. **Public** را انتخاب کن (رایگان و نامحدود برای Actions)
4. تیک «Add a README file» را **نزن**
5. دکمهٔ سبز **Create repository** را بزن

---

## مرحلهٔ ۲ — پوشهٔ `lua-audit` را آپلود کن

1. در صفحهٔ مخزن خالی، روی لینک **uploading an existing file** کلیک کن
   (یا: **Add file → Upload files**)
2. پوشهٔ **`lua-audit`** را از حالت Extract‌شده بکش و داخل کادر آپلود رها کن
   (فقط همین پوشه؛ `.github` را الان نمی‌خواهیم)
3. صبر کن تا اسم همهٔ فایل‌ها بالا بیاید
4. پایین صفحه دکمهٔ سبز **Commit changes** را بزن

بعد از این، در مخزن باید یک پوشهٔ `lua-audit` ببینی.

---

## مرحلهٔ ۳ — فایل «ورک‌فلو» را بساز (مهم‌ترین قدم)

این فایل به گیت‌هاب می‌گوید چه‌کار کند. یک‌بار برای همیشه می‌سازیمش.

**الف) محتوای فایل را کپی کن:**
1. در همین پوشهٔ `lua-audit\android` فایل **`build-apk.workflow.yml`** را باز کن
   (راست‌کلیک → Open with → **Notepad**)
2. در Notepad: `Ctrl+A` (انتخاب همه) بعد `Ctrl+C` (کپی)

**ب) فایل را در گیت‌هاب بساز:**
1. برگرد به صفحهٔ مخزن در گیت‌هاب
2. **Add file → Create new file**
3. در کادر نام فایل، این را **دقیقاً** تایپ کن (با `/` پوشه خودکار ساخته می‌شود):

   ```
   .github/workflows/build-apk.yml
   ```

4. داخل کادر بزرگ متن، `Ctrl+V` کن (محتوای کپی‌شده Paste می‌شود)
5. پایین صفحه **Commit changes** را بزن

> اگر موقع تایپ، گیت‌هاب خودش دو پوشهٔ `.github` و `workflows` را ساخت، یعنی درست است.

---

## مرحلهٔ ۴ — اجازهٔ اجرای Actions

1. در بالای صفحهٔ مخزن، تب **Actions** را بزن
2. اگر پیامی مثل *«Workflows aren't being run on this fork»* یا دکمهٔ سبز
   **I understand my workflows, go ahead and enable them** دیدی، آن را بزن

---

## مرحلهٔ ۵ — ساخت APK را شروع کن

1. در تب **Actions**، از ستون چپ **Build Android APK** را انتخاب کن
2. سمت راست دکمهٔ **Run workflow ▾** را بزن → دوباره **Run workflow**
3. چند ثانیه صبر کن؛ یک ردیف زرد رنگ با آیکون چرخان ظاهر می‌شود
4. روی همان ردیف کلیک کن. حدود **۲ تا ۵ دقیقه** طول می‌کشد تا سبز (✅) شود.
   (اگر زرد ماند، یک بار صفحه را Refresh کن)

---

## مرحلهٔ ۶ — APK را دانلود کن

1. روی همان اجرای سبز کلیک کن
2. پایین صفحه، بخش **Artifacts** را ببین
3. روی **SskidScriptScanner-apk** کلیک کن → یک فایل zip دانلود می‌شود
4. آن zip را Extract کن → داخلش **`app-debug.apk`** است ← همین فایل نهایی است

---

## مرحلهٔ ۷ — نصب روی گوشی

1. فایل `app-debug.apk` را به گوشی منتقل کن (کابل، بلوتوث، تلگرام به خودت…)
2. روی فایل بزن. اگر پیام آمد، اجازهٔ **«نصب از منابع ناشناس» / Install unknown apps**
   را برای همان برنامه (مثلاً Files یا Chrome) بده
3. نصب کن و بازش کن ✅

> این APK «دیباگ» است: خودش امضاشده و نصب می‌شود، فقط گوگل‌پلی آن را قبول نمی‌کند
> (که برای پخش بین دوستان مهم نیست).

---

## اگر جایی گیر کردی

- **فایل APK ساخته نشد و ردیف قرمز شد؟** روی اجرا کلیک کن، روی مرحلهٔ قرمزرنگ
  کلیک کن و متن خطا را برایم بفرست؛ درستش می‌کنم.
- **پوشهٔ `.github` را پیدا نمی‌کنی؟** لازم نیست پیدایش کنی — مرحلهٔ ۳ آن را
  خودکار در گیت‌هاب می‌سازد.
- **اصلاً نمی‌خواهی با گیت‌هاب ور بروی؟** می‌توانی همان فایل
  `lua-audit\web\SskidScanner.html` را در مرورگر گوشی‌ات باز کنی؛ همان اسکنر
  است، فقط به‌جای آیکون، یک بوکمارک می‌شود.
